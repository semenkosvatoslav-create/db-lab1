# Лабораторна робота № 1
**Тема:** Проектування бази даних та ознайомлення з базовими операціями СУБД PostgreSQL  
**Предметна галузь:** Інформаційна система бібліотеки (облік видачі книг читачам)  

## Структура репозиторію
* `init_db.sql` — повний SQL-скрипт для створення таблиць, зовнішніх ключів, обмежень цілісності та заповнення тестовими даними.
* `er-diagram.png` — концептуальна модель «сутність–зв'язок» (нотація Чена).
* `relational-schema.png` — реляційна схема таблиць бази даних.

## Використані технології
* СУБД: PostgreSQL 18
* Середовище адміністрування: pgAdmin 4
* Моделювання: diagrams.net
